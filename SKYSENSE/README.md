# SkySense — Weather App 🌤️

A weather app I built as my 2nd year JavaScript mini project. Uses real weather APIs, OpenAI for smart suggestions, and a fully dynamic UI that changes based on the current weather condition.

---

## Live Preview

Just open `index.html` in your browser — no server, no npm, nothing to install.

---

## Features

- **Live Weather Data** — search any city worldwide using the OpenWeatherMap API
- **Current Conditions** — temperature, feels like, weather description, visibility, pressure
- **Sunrise & Sunset** with today's date
- **Wind Speed & Humidity** shown in icon grid
- **5-Day Forecast** — daily high/low, weather icon, wind & humidity per day
- **AI Smart Suggestions** — clothing, activity and travel tips generated by GPT-4o-mini based on actual weather data. Falls back to local rule-based tips if the API key is expired
- **Dynamic Background** — the background gradient and animated blobs change colour to match the weather (dark navy for thunderstorm, steel blue for rain, white-blue for snow, bright sky for clear, etc.)
- **Animated Weather Emoji** — the logo emoji updates and pops when weather changes
- **Dark / Light Mode** — toggle with preference saved in `localStorage`
- **Loading Spinner** — shown while fetching data
- **Responsive** — works on mobile and desktop

## How to Run

1. Clone or download this repo
2. Open `SKYSENSE/index.html` in Chrome or Firefox
3. Type any city name and press **Enter** or click **Search**

> **Note:** The OpenWeatherMap API key included is a free tier key.
> The OpenAI key is included for demo purposes — if it's expired, the app automatically falls back to local rule-based suggestions so it still works.

## How the Dynamic Background Works

Every weather condition maps to a unique gradient and animated blob colours:

| Condition | Background |
|---|---|
| ⛈️ Thunderstorm | Deep dark navy / purple |
| 🌧️ Rain | Dark steel blue |
| 🌦️ Drizzle | Muted teal |
| ❄️ Snow | Soft white-blue |
| ☀️ Clear | Bright sky blue |
| ☁️ Clouds | Muted grey-blue |
| 🌫️ Fog / Mist / Haze | Warm grey |

The three blobs on the background also change colour to match, and they drift slowly using CSS keyframe animations to make the background feel alive.

---

## AI Suggestions

When a city is searched, the app sends a prompt to OpenAI GPT-4o-mini with the current temperature, weather condition, humidity and wind speed. It asks for 5 practical tips covering clothing, accessories, activity, health and travel — all returned with emojis.

If the API call fails (expired key, rate limit, etc.), it automatically uses local JavaScript logic instead, so there's always something shown.

## Known Limitations

- The 5-day forecast uses OpenWeatherMap's free tier which gives data every 3 hours — I filter for the noon entry to get one reading per day, so min/max values are for that snapshot, not the actual daily range
- No geolocation / auto-detect (could add this later)
- OpenAI suggestions require a valid paid API key to work; local fallback is always available
